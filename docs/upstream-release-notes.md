# 原版 Pulse 更新说明同步

核对日期：2026-10-31。最新正式版：[Pulse 1.12.4](https://github.com/qunqin24/Pulse/releases/tag/v1.12.4)，发布时间为北京时间 2026-10-24 20:09。

本文按官方发布记录整理中文摘要，覆盖本地原版参考之后的 **1.7.0–1.12.4，共 16 个版本**。版本日期统一使用 Asia/Shanghai；完整原文见每个版本的链接。

来源为 [GitHub Releases](https://github.com/qunqin24/Pulse/releases) 和 [1.9.0 对应提交的 CHANGELOG](https://github.com/qunqin24/Pulse/blob/cf08e42fcf6168c9f3c1c15902ce326eb6aa2507/CHANGELOG.md)。本地 `Pulse-original` 仍为提交 `397c8fc4f1bd52180a452d2f3f0c099def97cf69`，其更新记录最新条目为 1.6.1。此次同步的是发布说明和待跟进清单；PulseWin 当前发布版本为 0.1.17。

## 1.12.4 · 2026-10-24

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.12.4)

- 新增实验性「水滴式吸附」：从屏幕边缘拉开胶囊时像水滴一样拉长再断开，靠近边缘会被吸过去；设置 → 实验性功能，默认关闭。
- 新增测试通知：设置 → 通知 → 发送，立即收到一条测试通知，确认通知能正常送达。
- Cursor 加密保存登录后仍能读取用量：钥匙串请求被拒绝后改为下次启动或手动刷新时再询问。
- Cursor 企业账号只报告一个总额度时按月度额度显示，金额以美元计。
- Kimi Code 用量记录包含新版 Kimi Code 的会话记录，能识别模型时按公开价格估算。
- Codex 同一会话同时出现在 `sessions` 和 `archived_sessions` 中时只计算一次。
- 刘海处的胶囊按屏幕居中、过渡圆角与刘海一致；小尺寸且服务商较少时顶部圆角不再被切成直角。
- 详细卡片不再显示「按 API 价格估算」说明行，说明保留在设置 → Token 消耗。

## 1.12.3 · 2026-10-21

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.12.3)

- Antigravity 的 Gemini 3.8 Flash 按公开价格估算：记录中的 `-n`、`-control`、`-xpe` 变体与基础型号使用同一价格，不再显示为无公开价格。

## 1.12.2 · 2026-10-18

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.12.2)

- 新增日报和周报：设置 → Token 消耗 → 用量报告，在窗口顶部切换日、周、月、年，生成可分享的卡片。
- Token 消耗支持自定义统计区间：「统计方式」新增本月、上月、今年和自定义范围（可选开始和结束日期）。
- Qoder 显示积分数值和积分消耗记录：设置页可开启「显示积分数值」，卡片每行显示积分数（如 5,843 / 6,000）；详细卡与设置页显示账号今天、7 天和 31 天消耗与扣除积分，以及按天柱状图。
- Grok 的缓存和推理 token 不再重复计算，缓存命中率、Token 总数和估算金额与 Grok Build 自身记录一致。
- Antigravity 金额估算补充 Gemini 3.1 Pro 和 Gemini 3.5 Flash (Low) 的公开价格；仍有模型无公开价时金额后标注 `*`。
- Qoder 圆环固定在「积分额度」后，重启不再被重置。
- 设置窗口侧栏图标改为黑色（深色模式为白色），设置项中的选项改为弹出菜单。
- 缩短俄文的 Token 活动视图名称，切换按钮不再被截断。

## 1.12.0 · 2026-10-16

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.12.0)

- 新增 44 个服务商的官方服务状态：Copilot、Devin、Windsurf、Hugging Face、Gemini 等设置页显示官方状态页公布的状态和历史，可随时刷新；设置 → 通知 → 服务出故障时打开故障提醒。
- 估算金额可切换货币：设置 → 通用 → 货币可选人民币、港元、新台币、日元、韩元或卢布，按当日汇率或自填汇率换算；服务商自己报告的余额不换算。
- 连接诊断显示服务器原始回应：展开后可看每个请求的状态码和返回内容，凭证会被隐藏。
- Antigravity 支持 `agy` CLI：编辑器未运行时改用 CLI 读取额度，设置页的「用量来源」可选自动、CLI 或桌面端。
- MiniMax Code 用量记录：打开 Token 消耗后，MiniMax 卡片和设置页显示本机 MiniMax Code 的用量记录。
- 可关闭自动吸附到屏幕边缘：关闭后拖动只移动面板，可放在屏幕任何位置。
- 新增进度条样式：设置 → 外观 → 进度条可选连续或分段。
- MiniMax 与 MiniMax CN 合并为一个服务商：设置页选择国际站或国内站，两个站点各自保存 key，原 MiniMax CN 的 key 与设置启动时自动迁移。
- 设置窗口改为系统设置样式：侧栏延伸到窗口顶部，标题栏显示当前页面名称，并有前进/后退按钮（⌘[ 和 ⌘]）。
- 程序坞菜单里的「退出」只关闭窗口；⌘Q 和菜单栏图标中的「退出 Pulse」仍退出整个 app。
- 金额不再显示「US$」，美元统一写作「$」，估算金额前不再加「≈」。
- OpenCode Go 订阅到期时提示没有套餐，不再误报「key 被拒绝」。
- 改进 Codex「较弱模型迹象」：max 和 ultra 推理强度纳入比较，上下文窗口不再算作降级，推理在固定位置停下的比例只显示数字、不下结论。
- 刘海处的面板不会被路过的指针展开（需停留片刻），展开后立即按下的点击不会误刷新圆环。
- 指针离开后详情卡可靠收起；液态玻璃调得更透明时文字仍清晰（越过默认值后文字由白转黑）。
- 更省电、读取更快：面板收起时小机器人停止动画，本机用量读取更快、占用内存更少。
- 「读取途径检查」整行可点击展开。
