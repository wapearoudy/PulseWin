# 原版 Pulse 更新说明同步

核对日期：2026-11-15。最新正式版：[Pulse 1.13.0](https://github.com/qunqin24/Pulse/releases/tag/v1.13.0)，发布时间为北京时间 2026-11-11 11:07。

本文按官方发布记录整理中文摘要，覆盖本地原版参考之后的 **1.7.0–1.13.0，共 21 个版本**。版本日期统一使用 Asia/Shanghai；完整原文见每个版本的链接。

来源为 [GitHub Releases](https://github.com/qunqin24/Pulse/releases) 和 [1.9.0 对应提交的 CHANGELOG](https://github.com/qunqin24/Pulse/blob/cf08e42fcf6168c9f3c1c15902ce326eb6aa2507/CHANGELOG.md)。本地 `Pulse-original` 已更新到提交 `338c796`（2026-11-11，与 `origin/main` 同步，较此前参考多 277 个提交）。此次同步的是发布说明和待跟进清单；PulseWin 当前发布版本为 0.1.19。

## 1.13.0 · 2026-11-11

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.13.0)

- 扩展可以用 `pulse-extension.json` 里的 `icon` 指定一张 PNG，圆环、卡片、设置页与菜单栏里都以原色显示；不写则继续用默认图标。
- 支持 ego lite 浏览器：登录过的 ego lite 也能读取消用量。
- 设置项与操作按钮前显示小图标，扫一眼就能分清哪些行可以点。
- 关于页新增 Star 与爱发电入口；使用满两周后，设置窗口顶部提示一次 Star（只提示一次）。

## 1.12.7 · 2026-11-05

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.12.7)

- Antigravity 最多显示三个分组圆环（Gemini 4 的 Argon 周额度单独一个圆环），每个分组可单独关闭。
- 读取 Gemini.app 自带的 `agy`：只安装了 Gemini.app 时也能读到 Antigravity 的额度。
- 小米按量计费账号显示余额圆环，余额偏低时提醒。
- Command Code 工作时圆环显示转动标记。
- 带登录信息的请求不再跟随跨域跳转（Qoder、StepFun、小米、OpenCode Go、Claude Desktop）。

- 更换 Z.ai / 智谱 key 后卡片重新读取历史。
- 额外账号续期失败不再误报「已退出」：网络、限流、服务端错误保留上次读数。
- Command Code 的 `deepseek-v4.1-flash` 按 models.dev 的价格表计价。
- 用量记录从第一天开始就显示柱状图。

## 1.12.4 · 2026-10-24

- 刘海处的胶囊按屏幕居中、过渡圆角与刘海一致；小尺寸且服务商较少时顶部圆角不再被切成直角。

## 1.12.2 · 2026-10-18

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.12.2)

## 1.12.0 · 2026-10-16

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.12.0)

- 新增 44 个服务商的官方服务状态：Copilot、Devin、Windsurf、Hugging Face、Gemini 等设置页显示官方状态页公布的状态和历史，可随时刷新；设置 → 通知 → 服务出故障时打开故障提醒。
- 估算金额可切换货币：设置 → 通用 → 货币可选人民币、港元、新台币、日元、韩元或卢布，按当日汇率或自填汇率换算；服务商自己报告的余额不换算。
- 连接诊断显示服务器原始回应：展开后可看每个请求的状态码和返回内容，凭证会被隐藏。
- Antigravity 支持 `agy` CLI：编辑器未运行时改用 CLI 读取额度，设置页的「用量来源」可选自动、CLI 或桌面端。
- MiniMax Code 用量记录：打开 Token 消耗后，MiniMax 卡片和设置页显示本机 MiniMax Code 的用量记录。
- 可关闭自动吸附到屏幕边缘：关闭后拖动只移动面板，可放在屏幕任何位置。
- 新增进度条样式：设置 → 外观 → 进度条可选连续或分段。
- MiniMax 与 MiniMax CN 合并为一个服务商：设置页选择国际站或国内站，两个站点各自保存 key，原 MiniMax CN 的 key 与设置启动时自动迁移。
- 设置窗口改为系统设置样式：侧栏延伸到窗口顶部，标题栏显示当前页面名称，并有前进/后退按钮（⌘[ 和 ⌘]）。
- 程序坞菜单里的「退出」只关闭窗口；⌘Q 和菜单栏图标中的「退出 Pulse」仍退出整个 app。
- 金额不再显示「US$」，美元统一写作「$」，估算金额前不再加「≈」。
- OpenCode Go 订阅到期时提示没有套餐，不再误报「key 被拒绝」。
- 改进 Codex「较弱模型迹象」：max 和 ultra 推理强度纳入比较，上下文窗口不再算作降级，推理在固定位置停下的比例只显示数字、不下结论。
- 刘海处的面板不会被路过的指针展开（需停留片刻），展开后立即按下的点击不会误刷新圆环。
- 指针离开后详情卡可靠收起；液态玻璃调得更透明时文字仍清晰（越过默认值后文字由白转黑）。
- 更省电、读取更快：面板收起时小机器人停止动画，本机用量读取更快、占用内存更少。
- 「读取途径检查」整行可点击展开。

### 1.12.5–1.13.0 的差距摘要

这一批功能已在 **0.1.20 工作树**移植完成（2026-11-15），验证为 1310 个 Rust 测试（另有 2 个真实账号用例显式忽略）、287 个前端测试、81 个浏览器流程通过；0.1.20 尚未重建 Windows 原生产物，真机验收仍待做。

落地方式与偏差：

1. **DimAgent 提供商**（1.12.5）：新增 `dimagent` 提供商，跑 `dim usage --json`，解析套餐额度、加油包（独立窗口，不并入订阅分母）、token 窗口（5h/1d/7d）与网页搜索用量；未登录、限流、回复不可读各有独立文案。
2. **扩展 PNG 图标**（1.13.0）：扩展清单新增 `icon` 字段，校验路径（拒绝绝对路径与 `..`）、PNG 魔数、尺寸与大小上限、拒绝 APNG；圆环、卡片与设置页按原色渲染，**托盘图标仍用内置单色**。
3. **ego lite 浏览器读取**（1.13.0）：浏览器根新增 `Citro Labs\ego lite`，沿用 LevelDB 读取；DeepSeek 控制台的权限提示也列出 ego lite。
4. **Antigravity 分组圆环 + `agy` 来源**（1.12.0/1.12.7）：设置页可开启分组（最多三个圆环，槽位 id `account@group`，逐组可关，超过三组退回整体圆环）；新增 `agy` CLI 来源（`--log-file NUL -p /usage --output-format json`，30 秒期限，allow-list 环境），来源可选「自动/CLI/桌面端」。
5. **MiniMax 与 MiniMax CN 合并**（1.12.0）：只保留 `minimax` 一个提供商，设置页选择国际站/国内站；旧 key 启动时迁移，启用状态、顺序、标签、外观、固定窗口、分组与低余额提醒等设置折叠到新 id。

其余小项：详情卡滚动并可固定标题（1.12.8）、小米按量计费余额圆环与低余额提示、设置**分组标题与每个设置行**前的小图标（匹配不到的行保持无图标，操作按钮前未加）、关于页 Star/爱发电入口与「满两周且满七个自然日」提示一次、续期失败分八类且仅凭证被拒才要求重登录、Z.ai 换 key 后重读历史、切换站点丢弃旧站点读数、Command Code 按 models.dev 计价与工作转动标记、每日用量柱状图从第一天起显示、Devin 卡片归并 Oh My Pi 用量。多语言（1.11.0/1.12.6）PulseWin 未做，不适用；1.12.5 的「完全磁盘访问权限」是 macOS 权限语义，Windows 版改写为文件占用/权限不足并指引关闭浏览器后重试。

0.1.19 已发布，含 1.12.4 及之前的主要差距项；1.12.5–1.13.0 的移植在 0.1.20 工作树，release hold 继续生效。
