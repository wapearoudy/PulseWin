# 原版 Pulse 更新说明同步

核对日期：2026-10-11。最新正式版：[Pulse 1.9.0](https://github.com/qunqin24/Pulse/releases/tag/v1.9.0)，发布时间为北京时间 2026-10-09 13:31。

本文按官方发布记录整理中文摘要，覆盖本地原版参考之后的 **1.7.0–1.9.0，共 9 个版本**。版本日期统一使用 Asia/Shanghai；完整原文见每个版本的链接。

来源为 [GitHub Releases](https://github.com/qunqin24/Pulse/releases) 和 [1.9.0 对应提交的 CHANGELOG](https://github.com/qunqin24/Pulse/blob/cf08e42fcf6168c9f3c1c15902ce326eb6aa2507/CHANGELOG.md)。本地 `Pulse-original` 仍为提交 `397c8fc4f1bd52180a452d2f3f0c099def97cf69`，其更新记录最新条目为 1.6.1。此次同步的是发布说明和待跟进清单；PulseWin 当前程序版本仍为 0.1.14。

## 1.9.0 · 2026-10-09

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.9.0)

- 新增浅色助手：浅灰表面、深色文字和更深的警示色；与 Liquid Glass 互斥，浅色菜单也采用对应颜色。
- 工具清理源日志后保留已经读取的历史统计；无法追回此前已经丢失的记录。
- 调整刘海停靠宽度和顶部过渡曲线。
- 月报、年报按实际最活跃的连续四小时展示节奏；部分模型缺价时仍生成回本卡，明确金额只是下限。
- 回顾从首条本机记录起算；修正日均比较、通宵结束时间、星期几均值、缓存金额含义，以及缺价和缺少时段数据时的处理。
- 卡片明确标注未结束月份、中途开始记录和未来月份，修订回顾文案。

## 1.8.3 · 2026-10-08

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.8.3)

- 每日图表按 31 天固定柱宽，短历史从左侧排列，避免单日记录形成巨大色块并遮住卡片。
- Codex 额度余额采用当前语言的数字格式，最多两位小数。

## 1.8.2 · 2026-10-07

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.8.2)

- 不完整记录保留有证据的 Token 分类，明确报告的未分类总量单独展示；不推算缺失分类、不对未分类部分计价。
- 每日明细增加可排序的未分类列，无该类数据时隐藏；缺失的分类不显示为零。
- 统一输入、缓存命中、输出的展示术语；输入包含已记录的缓存写入。
- 修复超大整数排序和表头换行，并修订多语言界面及历史发布说明。

## 1.8.1 · 2026-10-06

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.8.1)

- GitHub 检查或下载失败时切换至备用更新通道，安装仍要求签名验证。
- 更新窗口按界面语言显示中文或英文说明。
- 外观调整只重新布局，不重新请求配额。
- 修复密钥保存与 DeepSeek 登录续期互相覆盖、删除后的登录被续期恢复的问题。
- Claude Code 钥匙串读取超时后改用其他路径，避免阻塞整体刷新。
- 修复月报大数字裁切，以及窄设置窗口和订阅价格输入布局。

## 1.8.0 · 2026-10-05

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.8.0)

- 新增可保存、复制、分享的月报和年报卡片：工具、日历、时段、订阅回本和总结；缺失数据不补零。
- 支持自定义订阅价格、隐藏项目名，以及默认关闭的月报生成通知。
- 新增最近十二个月的日、周和累计 Token 活动图。
- 合并 Claude Code 子代理会话，改进 Codex 会话标题及自动审查标识。
- 规范工作树项目归属，排除临时目录；修复部分 macOS 图标绘制，并在回顾窗口打开时显示 Dock 图标。

## 1.7.3 · 2026-10-05

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.7.3)

- 设置窗口打开时可显示 Dock 图标，便于找回被遮挡的设置。
- 修正 Codex 子任务继承历史造成的重复计数，纳入归档会话；调整一小时缓存写入、长上下文定价及多个来源的去重。
- 明确 Token 分类和未知缓存信息；近期统计按自然日计算，未知价格不显示为零。
- 修复删除账号与续期竞态、OpenCode 换账号后的旧历史、失效登录提示、仅额外账号时的刷新和窗口启动器唤醒。
- Go 月度时长不再固定为 30 天；异常服务响应更稳健，中文术语统一。

## 1.7.2 · 2026-10-04

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.7.2)

- Codex、Claude Code、DeepSeek 设置增加官方服务状态、90 天历史和公布的可用率，打开时读取并每五分钟更新。
- 新增默认关闭的服务故障通知，对故障出现、严重程度升级及恢复分别去重提醒。
- 打开关于页立即检查更新，减少 Token 汇总、记录扫描和面板跟随的重复计算。

## 1.7.1 · 2026-10-03

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.7.1)

- 新增 Codex 本机日志迹象分析，展示可能的推理截断或配置异常；这不能证明服务端实际模型发生变化。
- DeepSeek 可从浏览器已登录的控制台读取账号近 30 天消费、Token、模型占比和缓存命中率。
- 修复横向面板中数字与百分比位置；空间不足时详情卡可滚动。

## 1.7.0 · 2026-10-03

[官方发布说明](https://github.com/qunqin24/Pulse/releases/tag/v1.7.0)

- 新增按账号开启的详细卡、模型用量与速度统计、Codex 首字延迟及提示缓存剩余时间列表。
- OpenCode Go 可读取官网登录后的配额与逐请求账单，覆盖多设备实际扣费。
- 新增横向自由摆放和底部停靠。
- 修复 Claude Code 继续/分叉历史重复及分段输出少算；改进额度价值估算的时间边界、最低用量和多设备证据条件。
- 支持 OpenCode 2 记录，Token 读取转为后台持续更新，调整菜单栏图标及用量面板开关。
