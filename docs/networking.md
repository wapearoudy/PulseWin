# 网络与刷新（0.1.10）

对照原版 `Docs/networking.md`、`App/NetworkProxy.swift` 和 `Settings/SettingsView.swift`。默认跟随系统；不会因为打开设置、发现凭据或配置代理而启用账号。

## 用户行为

- 「设置 → 网络与刷新」集中代理和检查间隔；位置与行为只保留面板交互。
- 手动代理支持 HTTP CONNECT、SOCKS5，不支持代理用户名/密码。HTTP / SOCKS5 类型和系统 / 手动方式立即保存。
- 首次选择手动方式但尚未填地址时仍跟随系统。有效主机及 1–65535 端口按 Enter、离开整个输入区域或点击保存一起提交；在主机与端口之间移动不提交半份设置。
- 主机接受 DNS、IPv4、IPv6（可带 IPv6 方括号）；拒绝协议、路径、用户信息、无效端口。服务端独立校验；无效提交保留原代理。普通偏好保存使用后端权威网络设置，旧窗口不能覆盖新代理。
- 切换代理先建立新客户端，保存成功后替换，取消旧刷新及 Token 价格读取，重新检查已启用的账号。没有启用账号时不请求服务。失败保留明确错误，不生成 0% 用量。
- SOCKS5 通过代理解析远端域名；手动代理绕过 localhost、127/8、::1 与 IPv4 映射回环地址。
- 普通服务与登录交换使用同一客户端策略；自建网关继续禁止重定向。Antigravity 本地编辑器连接继续直接连接。
- Kiro / Alibaba Token Plan 的辅助命令保留原有环境白名单和 PATH 前导目录；手动 HTTP 覆盖 HTTP_PROXY / HTTPS_PROXY，SOCKS5 覆盖 ALL_PROXY，删除大小写变体和冲突值，设置回环 NO_PROXY。
- 软件更新独立使用系统代理，不受手动用量代理影响。系统模式保留环境变量优先级，其次使用 Windows 手动代理注册表设置；PAC / WPAD 尚未实现。
- 检查间隔提供自动及 2 / 5 / 10 / 30 分钟，复用原有活动与省电调度，只检查已启用账号。

## 关于页面与导航

侧栏按面板、应用、账号分组，增加网络与刷新、关于入口，图标及行高继承已有设置样式。关于版本由编译元数据提供；软件更新沿用已有签名更新流程，通用页保留更新入口。源码、原版、Vinz、LobeIcons、MorphBot 链接只接受预设键，许可文本随应用编译，不依赖网络下载。

## 验证

861 项 Rust 测试（另 1 项默认忽略）、181 项前端单元测试、58 项完整浏览器流程通过；更新来源控件样式补齐后，13 项网络 / 关于 / 更新流程回归通过。

Rust 本地监听器验证真实 HTTP 绝对 URI、HTTPS CONNECT、SOCKS5 远端 DNS / 无身份验证握手、回环绕过、网关重定向拒绝；辅助进程环境、IPv6、凭据遮蔽及旧偏好迁移有回归。所有代理服务器只响应测试，不转发外部请求。

`node scripts/network-smoke.mjs` 运行独立 APPDATA / WebView2 的实际发布程序，使用假 DeepSeek key 和本地 CONNECT 服务器，验证旧挂起请求取消、新代理立即重试、旧通用偏好不能覆盖网络配置、无效值拒绝、SOCKS5 与检查间隔重启恢复、实际版本和本地许可、原用户偏好字节不变。CONNECT 测试服务器必须读取 socket 才能观察 FIN；最初未读取导致假超时，修正后实际取消完成。

该批并不证明全部真实服务登录、所有辅助工具现场代理连接、Windows PAC、混合 DPI 或完整原版功能覆盖。发布证据与耗时见 [release-0.1.10.json](release-0.1.10.json)。
