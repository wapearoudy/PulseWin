PulseWin 0.1.20

本版按用户要求提交并发布当前已验证的改进。本版不宣称与 Pulse 1.13.0 达到 100% 功能覆盖。

- 服务商：新增 DimAgent（通过已登录的 dim CLI 读取套餐额度、加油包、5 小时/每日/每周 token 窗口与网页搜索额度）；MiniMax 与 MiniMax CN 合并为一个服务商，设置页选择国际站或国内站，旧 key 与相关设置在启动时自动迁移。
- Antigravity：最多三个分组圆环、可逐组关闭；新增读取 Gemini.app 自带 agy 的来源选择（自动/CLI/桌面端），与桌面端共用同一份回复映射。
- 小米：按量计费账号显示余额圆环，余额偏低时提醒。
- 扩展：清单可用 icon 指定 PNG，按原色显示在圆环、卡片与设置页；新增 ego lite 浏览器登录读取。
- 控制台：续期失败分八类，只有凭证被拒才要求重新登录，网络/限流/服务端错误保留上次读数并标注原因；切换站点丢弃旧站点读数；换 Z.ai / 智谱 key 后重读历史；DeepSeek 的权限提示在 Windows 下改为文件占用或权限不足，并列出 ego lite。
- Command Code：按 models.dev 计价；工作时圆环显示转动标记（读 ~/.commandcode/projects，忽略 .checkpoints.jsonl）。
- Token 消耗：每日用量柱状图从第一天起显示，只有一天记录时也会显示（同时保留小时分布）。
- Devin 卡片显示经 Oh My Pi 产生的用量，且不重复计数。
- 界面：详情卡过长时可滚动、标题固定在顶部；设置分组标题与设置行前显示小图标；关于页新增 Star 与爱发电入口，使用满两周且满七个自然日后在设置窗口顶部提示一次 Star（只提示一次）。
- 文档：同步原版 1.12.5–1.13.0 共 21 个版本的发布说明与差距清单。

验证：1310 个 Rust 测试通过（另有 2 个真实账号用例显式忽略）、287 个前端测试通过、81 个浏览器流程通过；tsc 与 vite 构建通过。
