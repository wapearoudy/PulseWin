PulseWin 0.1.19

本版按用户要求提交并发布当前已验证的改进。本版不宣称与 Pulse 1.12.4 达到 100% 功能覆盖。

- 同步原版 1.10.0–1.12.4 共 16 个版本的发布说明，并补齐可直接移植的差异：Qoder 积分分项（套餐积分、加油包、专属积分与到期批次）及 31 天积分历史；Cursor 周额度、企业总额度与按需额度；Codex max/ultra 弱模型信号修正。
- Token 消耗：全部 9 种统计区间加自定义起止日期；日报/周报回顾；按模型的每日明细表（可排序、分页），显示输出速度与首字延迟；缓存读取悬停卡与缓存节省估算；原版模型价格拼写别名。
- 界面：连续/分段进度条；系统设置式设置窗口（标题栏、前进/后退、Alt+←/→ 快捷键）；实验性水滴式吸附；刘海悬停 250ms 延迟；连接诊断与诊断信息复制。
- 开发者集成：`--json`、`--statusline`、只读 `--recap`、`pulsewin://account` 与 `pulsewin://recap` 链接，以及在设置页导出 PowerShell/POSIX 开发者套件。
- 控制台：DeepSeek 从浏览器 localStorage 导入并自动续期；OpenCode Go 从应用 cookie 自动续期；两者的每日账本接入详细卡。
- 回顾：周条带、成绩单每日圆点、环比标签、最忙一天与缓存命中率；月度回顾通知点击可打开 Token 消耗回顾。
- 后台消费预热（warmer）的 20 秒启动延迟与 10 分钟刷新间隔已有单测覆盖。

本版安装包将由 GitHub Actions 在 Windows 上构建并签名。发布前本机验证：Rust 1245 项通过、0 项失败、2 项默认忽略；前端单元 269 项通过（26 个文件）；`tsc --noEmit` 与 `vite build` 通过；浏览器全套件 81 项通过。

现有账号、凭据、设置与额度告警规则保留。可从「设置 → 通用 → 软件更新」更新并重启。

仍待补齐：安装器与已安装客户端升级实测、44 个官方状态页真实响应、屏幕捕获隐藏真机、汇率离线/429、真实扩展指标、真实账号首字延迟、多屏/DPI、Windows 窗口启动器真机、真实扩展程序与 Harness 稳定日志验收。
