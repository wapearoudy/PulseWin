PulseWin 0.1.16

本版按用户要求先发布当前已验证的改进；尚未移植的 Token 来源已从界面隐藏，开发清单继续保留。本版不宣称与 Pulse 1.9.0 达到 100% 功能覆盖。

- 修复切换账号后名称设置重复、混入其他账号的问题，未保存草稿按账号隔离。
- 桌面助手支持浅色外观、横向浮动和底部停靠，详情卡随位置换向。
- 新增官方服务状态历史、活动视图、月度/年度回顾及 PNG 导出。
- 新增 DeepSeek 与 OpenCode Go 独立网页登录账单；会话加密保存，支持重启恢复。OpenCode 请求日志按 ID 去重、分批续读，关闭账号会取消读取；不替换 Go API Key。
- 增加 Kiro、Kimi CLI、Pi、Oh My Pi、Kimchi、Amp、Droid、OpenClaw、Goose、Hermes、Zed 等本地 Token 读取；Crush 只识别费用来源，不推算 Token。
- 保留日志清理后的已读取计数，修复 Claude 流式回复少算及跨文件去重，改善缓存/长上下文计价和大整数显示。
- 新增 Codex 本地计数分析、Claude/Codex 缓存时限及有证据的输出速度/首 Token 延迟。
- 改善更新代理策略、GitHub 同仓库备用查询和发布说明语言选择。

现有账号、凭据、设置和时间进度额度告警规则保留。可从「设置 → 通用 → 软件更新」更新并重启。

仍待补齐：其他本地 Token 来源、完整详情卡/回顾视觉与分享流程、部分登录续期和扩展/集成功能。多屏、部分真实通知和真实 Harness 稳定日志验收仍未完成。
