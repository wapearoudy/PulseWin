PulseWin 0.1.22

- 修复桌面助手窗口尺寸裁切后不显示的问题，更新双圆环线宽和间距，新增 23 种机器人造型以及平面和毛绒材质。
- 用量详情卡可按账号选择显示内容。设置页用量条与详情卡共用显示样式，支持分段额度和按时间进度判断的告警。
- DeepSeek 与 OpenCode Go 的账单保留服务商报告的实际金额和币种。金额为零时显示 0，缺少金额时显示横线。
- 支持识别装在自定义目录的 Antigravity，以及 Windows 默认安装目录里的 `agy`。新版 Antigravity 桌面端用量通过已登录的 `agy` 读取。
- MiniMax 的国际站和中国站分别保存密钥与用量。修复应用已运行时打开 `pulsewin://` 账号链接的导航。

Windows 本地验证覆盖桌面助手、设置和 CLI 发现流程。真实账单和已登录的 `agy` 额度仍待实测。
